# Скрипти пошуку за arXiv

Команди послідовного запуску та фактичні результати є в [README проєкту](../README.md).

| Скрипт | Призначення |
| --- | --- |
| `01_prepare_data.py` | Перетворює arXiv JSONL на локальний Parquet. |
| `02_embed.py` | Кодує заголовки й анотації через SPECTER2 та перевіряє прив’язку ID. |
| `03_load_to_pinecone.py` | Валідує записи або завантажує їх батчами в Pinecone. |
| `04_search.py` | Виконує пошук, фільтри та порівняння cosine, dot і L2. |
| `05_chunking.py` | Порівнює фіксоване розбиття та пакування цілих речень. |
| `06_hybrid_search.py` | Порівнює BM25, векторний пошук і RRF. |

`embedding_model.py` встановлює спільну конфігурацію кодування та перевіряє маніфест. `vector_store.py` містить спільні операції Pinecone.
